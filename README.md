### 👨‍💻 About Me

I am a passionate **iOS & Mobile Systems Engineer** dedicated to engineering high-performance, polished mobile experiences. My work spans the entire lifecycle of consumer mobile products: from crafting declarative, reactive user interfaces in **SwiftUI** to architecting robust data pipelines, **Docker-containerized** backend services, and automated **App Store Connect & Apple Search Ads** growth engines.

- 🔭 **Core Focus:** Native iOS development (Swift 6, SwiftUI, SwiftData, Combine, Modern Concurrency)
- 🏗️ **Architecture:** Clean Architecture, Protocol-Oriented MVVM, Modular Design, Instruments Profiling
- 🚀 **Ecosystem & Growth:** App Store Connect APIs, Apple Search Ads (ASA) keyword mining & bidding automation, StoreKit 2
- 🐳 **Cloud & DevOps:** Docker, Docker Compose, PostgreSQL, Redis, Cloudflare, GitHub Actions CI/CD
